# Framework Figure

`SERA_overview.png` is the framework overview from Fig. 2 of
**SERA: Support Evidence Routing and Adaptation for FSIC with VLM**.
The PNG is a 300 dpi raster export of the original vector figure.
`SERA_overview.emf` preserves the source vector embedded in the manuscript.

The figure presents UEC, the independent REA branch, evaluation-time MEA, and
VPER. Labels and numerical content are preserved from the manuscript.
